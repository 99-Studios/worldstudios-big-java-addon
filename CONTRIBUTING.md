# Contributing to WorldStudios World

Thanks for wanting to contribute!

## Before contributing

Please make sure your changes fit the goals of WorldStudios World:
- Add quality gameplay content.
- Keep each dimension's identity unique.
- Avoid adding features that do not improve the experience.

## Pull Requests

To contribute:

1. Fork the WorldStudios World repository.
2. Clone your fork to your computer.
3. Create a new branch for your changes.
4. Make your changes.
5. Push your branch to your fork.
6. Open a Pull Request to this repository.

Please include:
- A description of what you changed.
- Any testing you performed.

## Bug Fixes

When reporting or fixing bugs:
- Describe what happened.
- Include steps to reproduce it.
- Include your Minecraft and mod version.

Try to keep code organized and readable.

Thanks for helping improve WorldStudios World!
